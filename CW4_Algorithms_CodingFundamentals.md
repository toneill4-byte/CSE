# Activity 1.1.2

## 🎯 Learning Objectives
By the end of the project, students should be able to:
1. Understand how to store and retrieve data from a variable.
2. Concatenate (join) different data types together (e.g., strings and numeric values).
3. Develop algorithmic thinking (follow a set of steps to produce a desired result).
4. Develop an understanding of making things move on the screen and locating where items are on the screen.
